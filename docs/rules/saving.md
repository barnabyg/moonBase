# Saving

"Save" in the top bar saves the Campaign as a `.moonbase` file named after the game clock, where you choose in the save dialog, and "Load" carries on from a file you choose in the open dialog, in place of the Campaign you're playing. Both dialogs start in the folder you last used. The game-over screen has both buttons. The game keeps no Campaign itself, only the files you save (ADR-0006), so a Campaign you haven't saved is lost when the game closes, and it asks first: closing its window, or quitting, with progress since you last saved or loaded (or since the Campaign started) asks whether to save it. Save opens the save dialog and closes once the file is written, and cancelling that dialog keeps the game open; Don't save closes; Cancel keeps playing. With nothing unsaved, or on the game-over screen, it closes at once. A file that isn't a Moon Base save, is damaged, or comes from a newer version of the game is refused, and the Campaign you're playing carries on.
