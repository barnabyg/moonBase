# Browser game in TypeScript with Three.js

The game runs in the browser, written in strict TypeScript, built with Vite and rendered in 3D with Three.js. Lighting is part of the gameplay, because the base needs artificial lights and stored power to keep working through the Night, and the south pole's look depends on a low sun casting long shadows. That favours a real-time 3D renderer over 2D isometric sprites. We chose Three.js over Godot or Unity to keep a single TypeScript codebase shared with the headless simulation (ADR-0003). We chose it over Babylon.js for its larger ecosystem. Robots and Structures will be low-poly models built in code, with physically based materials, which gets decent visuals without a dedicated artist. The only supported target is desktop Firefox. Other browsers and mobile devices are explicitly out of scope, so we don't need to support browser-specific APIs such as Chromium's File System Access. Packaging as a desktop app (Tauri) is deferred.
